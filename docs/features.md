# MoodFlow - 全機能ドキュメント

## 概要

MoodFlowは、会議やプレゼンテーション中の参加者のムード（感情）をリアルタイムで可視化・分析し、より良いコミュニケーションを実現するためのツールです。

---

## 機能一覧とバックエンドサービス

### 1. リアルタイムムード収集

| 項目 | 内容 |
|------|------|
| **機能** | 参加者が絵文字でリアクションを送信 |
| **バックエンドサービス** | Express.js + Prisma + PostgreSQL (Supabase) |
| **活用方法** | 発表中のリアルな反応を把握し、内容の調整やペース配分に活かせる |

**API**: `POST /api/submit-mood`

```json
{
  "sessionId": "session-123",
  "nickname": "田中",
  "score": 3,      // -5 〜 +5
  "emoji": "😊"
}
```

---

### 2. リアルタイム文字起こし

| 項目 | 内容 |
|------|------|
| **機能** | 発表者の音声をリアルタイムでテキスト化 |
| **バックエンドサービス** | Google Cloud Speech-to-Text API |
| **活用方法** | 議事録の自動作成、後からの振り返り、AIによる内容分析 |

**技術詳細**:
- Socket.IO でブラウザからマイク音声をストリーミング
- Google Cloud Speech Client で日本語認識
- 認識結果を Prisma 経由でデータベースに保存

**環境変数**:
```
GOOGLE_CLIENT_EMAIL=xxx@xxx.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n..."
```

---

### 3. AI要約・トピック抽出

| 項目 | 内容 |
|------|------|
| **機能** | 文字起こしデータから主要トピックを自動抽出 |
| **バックエンドサービス** | Google Gemini API |
| **活用方法** | 長時間会議のポイント把握、参加者への話題共有 |

**API**: `GET /api/get-summaries?sessionId=xxx`

**スケジューラ**: 5分ごとに自動実行（`lib/scheduler.js`）

---

### 4. セッション後アンケート

| 項目 | 内容 |
|------|------|
| **機能** | セッション終了後に参加者からフィードバックを収集 |
| **バックエンドサービス** | Prisma + PostgreSQL (Supabase) |
| **活用方法** | 定量的な満足度評価、自由記述による改善点収集 |

**API**: 
- `POST /api/submit-survey` - アンケート送信
- `GET /api/get-survey` - アンケート結果取得

**アンケート項目**:
- 満足度（1-5）
- 今後参加したいか
- 良かった点
- 改善点

---

### 5. AI分析レポート

| 項目 | 内容 |
|------|------|
| **機能** | ムード・文字起こし・アンケートを統合してAI分析 |
| **バックエンドサービス** | Google Gemini API |
| **活用方法** | 会議の振り返り、次回への改善点の明確化 |

**API**: `POST /api/analyze-session`

```json
{
  "sessionId": "session-123",
  "targetLanguage": "ja"
}
```

**分析内容**:
- ムードトレンド分析
- 時間帯ごとの盛り上がり
- 文字起こしとムードの相関
- アンケート結果の統計
- 具体的な改善提案

---

### 6. ユーモア介入システム（A2A）

| 項目 | 内容 |
|------|------|
| **機能** | ムード低下時にAIエージェント対話で改善提案 |
| **バックエンドサービス** | Google Gemini API + Google Custom Search API |
| **活用方法** | 会議中の重い空気を和らげる具体的なアクション提案 |

**API**: 
- `POST /api/humor-intervention` - 介入提案を取得
- `POST /api/rate-intervention` - 効果を評価（学習用）

**エージェント構成**:
| エージェント | 役割 | 特徴 |
|-------------|------|------|
| HostAgent | MC | 状況分析、振り分け |
| KansaiAgent | ボケ役 | 関西弁、ユーモア |
| KantoAgent | ツッコミ役 | 標準語、冷静 |

**学習機能**: 
- 過去の成功事例（rating >= 4）をRAGで参照
- 将来的にOpenAI Fine-tuningへの拡張可能

---

### 7. 質問収集・投票

| 項目 | 内容 |
|------|------|
| **機能** | 参加者からの質問を収集し、投票で優先度決定 |
| **バックエンドサービス** | Prisma + PostgreSQL |
| **活用方法** | Q&Aセッションの効率化、参加者の関心事項の把握 |

**API**: `GET/POST /api/questions`

---

### 8. セッション管理

| 項目 | 内容 |
|------|------|
| **機能** | セッションの作成・開始・終了を管理者が制御 |
| **バックエンドサービス** | Prisma + PostgreSQL |
| **活用方法** | 参加者の入退室管理、セッションの開始/終了通知 |

**API**: 
- `GET/POST /api/session` - セッション状態管理
- `GET/POST /api/my-sessions` - 自分のセッション一覧

---

| 項目 | 内容 |

| **機能** | セッションデータをCSV/JSON形式でエクスポート |
| **バックエンドサービス** | Express.js |
| **活用方法** | 外部ツールでの分析、レポート作成 |

**API**: `GET /api/export?sessionId=xxx`

---

### 10. コホート分析

| 項目 | 内容 |
|------|------|
| **機能** | 役職・部署別のムード傾向を分析 |
| **バックエンドサービス** | Prisma + PostgreSQL |
| **活用方法** | 組織全体のエンゲージメント把握 |

**API**: `GET /api/cohort-stats?sessionId=xxx`

## 使用サービス一覧

| サービス | 用途 | 環境変数 |
|----------|------|----------|
| **Supabase (PostgreSQL)** | データベース | `DATABASE_URL` |
| **Google Gemini** | AI分析・生成 | `GEMINI_API_KEY` |
| **Google Cloud Speech** | 音声認識 | `GOOGLE_CLIENT_EMAIL`, `GOOGLE_PRIVATE_KEY` |
| **Google Custom Search** | ウェブ検索 | `GOOGLE_SEARCH_ENGINE_ID` |
| **Google Slides** | レポート生成（オプション） | `GOOGLE_SERVICE_ACCOUNT_JSON` |

## ユースケース

### ユースケース1: 全社会議
1. 管理者がセッションを作成・開始
2. 参加者がQRコードまたはURLから参加
3. リアルタイムでムードを可視化
4. 文字起こしで議事録を自動作成
5. 終了後アンケートを収集
6. AI分析で次回への改善点を把握

### ユースケース2: プレゼン練習
1. プレゼンターがセッションを開始
2. 練習相手がムードでフィードバック
3. どこで反応が悪かったか可視化
4. AI分析で改善アドバイスを取得

### ユースケース3: ワークショップ
1. ファシリテーターがセッションを管理
2. 参加者の質問を収集・投票で優先度決定
3. ムードが下がったらAI介入提案を活用
4. セッション後のアンケートで改善点を収集
