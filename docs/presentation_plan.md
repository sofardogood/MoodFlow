# 補佐やねん ハッカソンプレゼン (1分半)

## 構成概要

| セクション | 時間 | 内容 |
|-----------|------|------|
| コンセプト | 10秒 | 一言で伝える |
| 課題 | 15秒 | 問題提起 |
| 機能紹介 | 35秒 | 5つのメイン機能 |
| 技術 | 20秒 | A2A + 学習サイクル |
| まとめ | 10秒 | 締め |

---

## スライド1: コンセプト (10秒)

**キャッチコピー**:
> **「会議を可視化し、分析し、その場で変える」**

**トーク**:
「補佐やねんは、**リアルタイムの反応収集から、AI分析、そしてその場での介入まで**を一気通貫で行う会議支援AIです。」

---

## スライド2: 課題 (15秒)

**トーク**:
「オンライン会議や研修で、**参加者の本音が見えない**。誰も質問しない、反応がない。終わった後に『良かったですか？』と聞いても本音は出ない。

既存ツールは**事後分析**か**受動的な投票**。**リアルタイムで状況を把握して、その場で改善できるツール**がありませんでした。」

---

## スライド3: 機能紹介 (35秒)

**画面**: 5つの機能アイコン

### 5つのメイン機能

| 機能 | 説明 |
|------|------|
| **① リアルタイムリアクション** | 参加者が絵文字でムードを送信。グラフでリアルタイム可視化 |
| **② 匿名Q&A・要望** | 参加者はいつでも匿名で質問や要望を送信可能 |
| **③ 録音・文字起こし** | 会議を録音し、Google Speech-to-Textで文字起こし |
| **④ AI時系列分析** | 会議終了後、**どの時間帯で何が良かった/悪かったか**をAIが分析 |
| **⑤ リアルタイム介入(A2A)** | ムードが悪くなったらAIが**休憩提案や話し方のアドバイス**を提示 |

**トーク**:
「まず、参加者は**スマホから絵文字でリアクション**を送れます。これがリアルタイムでグラフ化されます。

**匿名で質問や要望**もいつでも送れるので、発言しにくい人も参加できます。

会議は**録音・文字起こし**されるので、終了後に**AIが時系列で分析**。どの話題でムードが下がったか、何が良かったかが分かります。

そして、**リアルタイムでムードが悪くなったら、AIが介入**。休憩の提案や、お笑い芸人のテクニックを参考にした具体的なセリフを提案します。」

---

## スライド4: 技術と学習サイクル (20秒)

**画面**: A2Aアーキテクチャ + 学習サイクル図

```
    ┌─────────────────────────────────────────────┐
    │           学習サイクル                       │
    │  会議データ蓄積 → AI精度向上 → 次の会議で活用 │
    └─────────────────────────────────────────────┘
              ↓
    ┌─────────────────────────────────────────────┐
    │  A2A (Agent-to-Agent) アーキテクチャ         │
    │  HostAgent → 関西/関東Agent → 警告生成       │
    │  + Google検索(芸人テクニック) + RAG(成功事例) │
    └─────────────────────────────────────────────┘
```

**トーク**:
「技術的には**A2A（Agent-to-Agent）**。ホストエージェントが方言を検出し、関西弁なら関西エージェント、標準語なら関東エージェントに相談。**Google検索でプロの話術も取得**します。

重要なのは**学習サイクル**。すべてのデータがDBに蓄積され、**会議を重ねるほどAIの精度が上がる**仕組みです。成功した介入は次回以降のプロンプトに反映されます。」

---

## スライド5: 活用シーン (オプション・質疑応答用)

| シーン | 活用方法 |
|--------|----------|
| **研修・セミナー** | リアクション + Q&A + AI分析で効果測定 |
| **大学講義** | 匿名質問で参加しやすく、理解度をリアルタイム把握 |
| **営業・面接** | 録音 + AI分析（プロンプト変更で対応） |
| **社内会議** | 議事録 + 雰囲気分析 + リアルタイム介入 |

---

## スライド6: まとめ (10秒)

**トーク**:
「**補佐やねん**は、可視化・分析・介入を一気通貫で行い、使えば使うほど賢くなるAI会議支援システムです。ありがとうございました。」

---

## 技術スタック（質疑応答用）

| 技術 | 用途 |
|------|------|
| **Google Gemini API** | AI分析、トピック抽出、A2Aエージェント |
| **Google Custom Search API** | お笑い芸人のテクニック検索 |
| **Google Cloud Speech-to-Text** | リアルタイム音声認識 |
| **Socket.IO** | リアルタイム音声ストリーミング |
| **Prisma + Supabase** | データベース（ムード、質問、介入ログ） |
| **Express.js** | バックエンドサーバー |

## キーワード（審査員向け）

- **A2A (Agent-to-Agent)**: 複数AIエージェントの協調
- **RAG**: 過去の成功事例からの学習
- **リアルタイム介入**: 可視化にとどまらない能動的アクション
- **学習サイクル**: 使うほど精度が上がる仕組み
- **汎用性**: 研修・講義・営業・面接に応用可能
