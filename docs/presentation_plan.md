# 補佐やねん ハッカソンプレゼン (1分半)

## 構成概要

| セクション | 時間 | 内容 |
|-----------|------|------|
| コンセプト | 15秒 | 一言で伝える |
| 課題とアイデア | 30秒 | 問題提起と解決アプローチ |
| 技術 | 30秒 | A2A + ウェブ検索 + RAG |
| まとめ | 15秒 | 締め |

---

## スライド1: コンセプト (15秒)

**画面**: ロゴ + キャッチコピー

**キャッチコピー**:
> **「場の空気を読み、お笑い芸人のテクニックで変える」**

**トーク**:
「補佐やねんは、**会議の雰囲気が悪くなったときにAIが自動で介入し、プロの芸人の話術を参考に具体的なアドバイスを出す**システムです。」

---

## スライド2: 課題とアイデア (30秒)

**画面**: 問題のイメージ（沈黙の会議） → 解決のイメージ（警告メッセージ）

### 課題
**トーク**:
「オンライン会議での『お通夜状態』。誰も発言しない、反応がない。進行役は焦って空回り。**既存のツールは可視化や事後分析まで**。リアルタイムで助けてくれるものがありませんでした。」

### アイデア
**トーク**:
「そこで私たちは**『可視化』だけでなく『介入』まで行うAI**を作りました。参加者のムードをリアルタイムで検知し、悪くなったら**お笑い芸人の話術を検索して、その場で使える具体的なセリフを提案**します。」

---

## スライド3: 技術 (30秒)

**画面**: A2Aアーキテクチャ図

```
┌─────────────────────────────────────────────────────┐
│               A2A (Agent-to-Agent)                  │
├─────────────────────────────────────────────────────┤
│  ⓪ Google検索: 芸人のテクニックを取得               │
│       ↓                                             │
│  ① HostAgent: 会議の方言を検出                      │
│       ↓                                             │
│  ② 関西弁 → 関西Agent / 標準語 → 関東Agent          │
│       ↓                                             │
│  ③ 過去の成功事例(RAG) + 検索結果を参照しアドバイス  │
│       ↓                                             │
│  ④ HostAgent: 短い警告メッセージに要約              │
└─────────────────────────────────────────────────────┘
```

**トーク**:
「技術的には**A2A（Agent-to-Agent）アーキテクチャ**を採用。ホストエージェントが会議の言語スタイルを検出し、関西弁なら関西エージェント、標準語なら関東エージェントに相談します。

さらに**Google Custom Search**で『お笑い芸人 話の振り方』を検索し、プロのテクニックを取得。**RAG（Retrieval-Augmented Generation）**で過去の成功事例も参照します。

単一AIではなく、**複数エージェントの協調 + リアルタイム検索 + 学習機能**で、場に合わせた柔軟な対応を実現しています。」

---

## スライド4: まとめ (15秒)

**画面**: デモ画面 or QRコード

**トーク**:
「**補佐やねん**は、可視化だけでなく、プロの技を学んでその場で助け舟を出すAIです。ぜひ体験してください。ありがとうございました。」

---

## 技術スタック（質疑応答用）

| 技術 | 用途 |
|------|------|
| **Google Gemini API** | AIエージェント（HostAgent, 関西Agent, 関東Agent） |
| **Google Custom Search API** | お笑い芸人のテクニック検索 |
| **Google Cloud Speech-to-Text** | リアルタイム音声認識 |
| **Prisma + Supabase (PostgreSQL)** | データベース（ムード、介入ログ） |
| **Socket.IO** | リアルタイム音声ストリーミング |
| **Express.js** | バックエンドサーバー |

## キーワード（審査員向け）

- **A2A (Agent-to-Agent)**: 複数AIエージェントの協調
- **RAG (Retrieval-Augmented Generation)**: 過去の成功事例からの学習
- **リアルタイム介入**: 可視化にとどまらない能動的アクション
- **ウェブ検索連携**: プロの話術をリアルタイムで取得
