# 補佐やねん プレゼンテーション構成案 (90秒ピッチ)

## 1. システム要約（一言で言うと？）

**「場の空気を読み、言語に合わせて助け舟を出すAIファシリテーター」**

> **ポイント**: 補佐やねんは会議の「方言（関西弁/標準語）」を自動検出し、その場に合ったスタイルでファシリテーションを支援します。これは**A2A（Agent-to-Agent）アーキテクチャ**で実現しています。

---

## 2. 競合・ポジショニング

| サービス | 特徴 | 補佐やねんとの違い |
|----------|------|-------------------|
| **Slido / Mentimeter** | リアルタイム投票・Q&A | 参加者の「能動的な行動」が必要。補佐やねんは**自動検出・自動介入**。 |
| **Microsoft Copilot / Zoom AI** | 要約・議事録・感情分析 | 事後分析がメイン。補佐やねんは**リアルタイムで介入**する。 |
| **ChatGPT / Claude** | 汎用AI | 単一エージェント。補佐やねんは**複数エージェントが協調（A2A）**。 |

**補佐やねんの勝ち筋**:
- **A2A (Agent-to-Agent)**: ホストエージェントが最適な専門エージェントを選び、協調して解決策を提示
- **リアルタイム介入**: 可視化だけでなく、具体的なアクション提案まで行う

---

## 3. 90秒ピッチ スライド構成案

### **スライド1: 課題 (Problem) - 15秒**
*   **ビジュアル**: オンライン会議で全員無言、重苦しい雰囲気
*   **テキスト**: 「会議の『お通夜状態』、どうしていますか？」
*   **トーク**:
    *   「オンライン会議で誰も発言しない、反応がない…皆さん経験ありますよね？」
    *   「進行役は焦って空回り。参加者も気まずい。」

### **スライド2: 解決策 (Solution) - 25秒**
*   **ビジュアル**: 補佐やねんのダッシュボード（ムードグラフ + 警告メッセージ）
*   **テキスト**: **補佐やねん: 空気を読んで、助け舟を出す**
*   **トーク**:
    *   「そこで開発したのが『補佐やねん』です。」
    *   「参加者の感情をリアルタイムで可視化。」
    *   「さらに、雰囲気が悪くなるとAIが自動で**警告と具体的なセリフ**を提案してくれます。」

### **スライド3: 技術的強み - A2A (Unique Value) - 35秒**
*   **ビジュアル**: A2Aアーキテクチャ図（HostAgent → 関西/関東エージェント → 警告）
*   **テキスト**: **A2A (Agent-to-Agent) で場に合わせた介入**
*   **トーク**:
    *   **「ここが技術的なポイントです。」**
    *   「ホストエージェントが会議の言葉遣いを分析。関西弁なら関西エージェント、標準語なら関東エージェントに相談します。」
    *   「各エージェントが専門的なアドバイスを生成し、ホストが短い警告メッセージにまとめて発表者に表示。」
    *   「これが**A2A（Agent-to-Agent）アーキテクチャ**。単一AIでは実現できない、場に合わせた柔軟な対応が可能です。」

### **スライド4: まとめ (Closing) - 15秒**
*   **ビジュアル**: ロゴとQRコード
*   **テキスト**: **場の空気を読み、変える。補佐やねん**
*   **トーク**:
    *   「分析するだけでなく、その場で助け舟を出すAI。」
    *   「補佐やねんで、孤独なプレゼンターをなくしましょう。」
    *   「ありがとうございました。」

---

## 4. デモで見せるべきポイント

1.  **ムード送信**: スマホで絵文字を押し、ダッシュボードのグラフがリアルタイムで動く様子
2.  **方言検出 + 警告**: 関西弁で話している会議に対して、関西エージェントからのアドバイスが警告として表示される様子
3.  **A2A可視化**: 「dialect: kansai, agentUsed: 関西エージェント」というAPIレスポンスを見せ、エージェント選択が動的に行われていることをアピール
